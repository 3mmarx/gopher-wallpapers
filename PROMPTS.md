# Prompts

The exact prompts used to generate each wallpaper.

Keeping these public makes the collection reproducible — anyone can
re-render a wallpaper they like, or use a prompt as a starting point for a
new one. Fill in the table below as you go; the rows are regenerated from
the files on disk by `python3 scripts/update-docs.py`, so keep the markers
intact and don't reorder the file column.

Regenerating the table (this will drop any prompt text you have added, so
copy it out first if the table isn't in sync):

```sh
python3 scripts/update-docs.py
```
