# gopher-wallpapers

Wallpapers of the Go gopher, rendered in pixel art.

**61 wallpapers · 2752 × 1536 · [CC0 1.0](LICENSE) public domain**

## About

A growing collection of pixel-art wallpapers depicting the Go gopher in
everyday scenes — running a bakery, piloting a pirate ship, coding in the
rain. New wallpapers and new art styles get added over time.

Everything here is free to use for anything, including commercially.
See [LICENSE](LICENSE).

> **Not affiliated with the Go project.**
> The Go gopher is a trademark of Google LLC. These images are original
> pixel-art renderings and are not the official Go mascot artwork.

## Styles

| Style | Wallpapers | Folder |
| --- | --- | --- |
| Pixel art | 61 | [`wallpapers/pixel-art/`](wallpapers/pixel-art) |

Adding a new style is just a new folder under `wallpapers/` plus a matching
folder under `previews/` — see [CONTRIBUTING.md](CONTRIBUTING.md).

## Installing

**macOS** — Finder → right-click → *Set as Desktop Picture*.

**Linux (GNOME)** — copy to `~/Pictures/Wallpapers/`, then
Settings → Appearance → Background → *Add Picture*.

**Windows** — right-click → *Set as background*, or Settings →
Personalization → Background → *Browse*.

## Using it in your own project

Clone it and point your wallpaper picker at `wallpapers/`:

```sh
git clone --depth 1 https://github.com/YOUR_USERNAME/gopher-wallpapers.git
```

Everything is plain `.jpg` in flat folders — no symlinks, no sidecar
metadata, nothing that needs a build step.

## Regenerating assets

Wallpapers are re-encoded from the pristine originals, and previews and the
gallery above are generated from the wallpapers:

```sh
./scripts/reencode.sh       # originals -> wallpapers/<style>/  at q82
./scripts/make-previews.sh  # wallpapers -> previews/<style>/   at 960px
python3 scripts/update-docs.py
```
