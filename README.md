## Installing

**macOS** — open the image in Preview, then *File → Set as Desktop Picture*.

**Linux** — copy to `~/Pictures/Wallpapers/`, then
Settings → Appearance → Background → *Add Picture*.

**Windows** — right-click the image → *Set as background*.

## Downloading the whole set

```sh
git clone --depth 1 https://github.com/3mmarx/gopher-wallpapers.git
```

Everything lives in `wallpapers/` as plain `.jpg` files. `previews/` has a
smaller 960px version of each one, if that's all you need.
